Reclaim SOL locked in empty token accounts.

This is Grabster as one HTML file. The interface and signing run here, in this browser tab. Reading Solana and sending transactions go to the RPC shown on this page. The page makes no other requests.

How this file works

Interface and signing
Run from this file, in this tab.
Reads and sends
Go to RPC: —. Needs internet. Change the RPC URL below if you have your own.
Checking an address
No private key needed. Paste any address and press Scan.
Closing accounts
Needs a signature. Paste the wallet's private key, which stays in this tab, or connect Phantom or Solflare. Extensions need this file opened from http://localhost, not file://.
Where the rent goes
Back to the wallet that owns the accounts. That wallet pays the network fee.
Grabster fee
Grabster keeps of the rent these transactions recover. It's inside the transaction and shown in the review.
